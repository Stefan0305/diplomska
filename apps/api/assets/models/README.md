# Built-in models

GLB files in this folder are committed to git and registered as built-in models by the seed script
(`prisma/seed.ts`), using `models.json` (file, display name, category). They are served at
`/files/models/<file>`.

To add a model: put the `.glb` here, add an entry to `models.json`, then run `npm run db:seed`.

Record the source and licence of every model. All current models are generated by
`scripts/generate-models.ts` (built-in set in `scripts/catalog.ts`, low-poly, modelled at real-world
size with the base on y = 0), so they are the project's own work and need no third-party licence.
Uploaded models remain the responsibility of the user who uploads them.
